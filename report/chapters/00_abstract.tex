\begin{abstract}
Sign language serves as the primary mode of interpersonal communication for millions of deaf and hard-of-hearing individuals worldwide. In India, Indian Sign Language (ISL) is characterized by rich grammatical syntax, dynamic two-handed spatio-temporal gestures, and subtle non-manual markers. However, the substantial communication barrier between the deaf community and the hearing majority remains a critical socio-technical challenge due to a persistent shortage of certified human interpreters and automated assistive technologies. 

This case study report presents the design, architectural implementation, empirical evaluation, and full-stack deployment of \textbf{SignBridge}---an end-to-end deep learning framework and web application engineered to recognize 76 dynamic ISL word classes from video clips. The SignBridge pipeline ingests dynamic RGB video recordings (primarily in QuickTime \texttt{.MOV} and MPEG-4 \texttt{.mp4} formats), uniformly extracts a normalized temporal sequence of 33 frames per clip, resizes and normalizes the visual stream, and performs multi-class neural inference.

To rigorously evaluate representative deep learning paradigms for dynamic ISL recognition under limited data constraints, three distinct model architectures were trained and systematically benchmarked on an identical 1,166-video dataset (comprising 806 training, 180 validation, and 180 held-out test video samples):
\begin{enumerate}
    \item \textbf{MobileNetV2 with Frozen Backbone Transfer Learning}: An ImageNet-pretrained lightweight inverted residual convolutional network whose deep feature representations remain frozen, followed by Global Average Pooling, a Dense layer of 256 units with ReLU, Dropout ($p=0.3$), and a 76-way Softmax classification head. Video-level predictions are derived via multi-frame temporal probability averaging.
    \item \textbf{Custom 2D Convolutional Neural Network (Baseline)}: A scratch-trained 3-block convolutional network (32, 64, and 128 filters with $3\times3$ kernels, ReLU activations, and $2\times2$ max-pooling), followed by Global Average Pooling, a Dense layer of 128 units, Dropout ($p=0.3$), and a 76-way Softmax classifier.
    \item \textbf{CNN-LSTM Spatio-Temporal Model}: A joint architecture pairing TimeDistributed 2D convolutional feature extraction layers with an LSTM recurrent network (128 hidden units) to directly capture ordered sequential transitions across all 33 frames, feeding into a 76-way Softmax classification head.
\end{enumerate}

Empirical evaluation on the held-out 180-video test set demonstrates that the transfer-learning \textbf{MobileNetV2} model substantially outperforms all scratch-trained counterparts, achieving a top test accuracy of \textbf{67.78\%} and a Macro $F_1$-score of \textbf{66.42\%}. In contrast, the scratch-trained Custom 2D CNN and CNN-LSTM models achieved \textbf{5.00\%} and \textbf{4.44\%} test accuracy, respectively. These results underscore the severe sample-efficiency bottleneck of optimizing high-capacity spatial and recurrent parameters from scratch across 76 discrete gesture classes with limited training video samples, whereas transfer learning with frozen pre-trained visual priors successfully generalizes without catastrophic overfitting. An equal-weight late-fusion ensemble achieved \textbf{60.56\%} test accuracy, demonstrating that fusing underperforming scratch models pulls down the superior predictive capability of the standalone MobileNetV2.

The production system integrates a high-performance Python backend powered by FastAPI and Uvicorn, which caches neural model weights as an in-memory singleton to deliver low-latency inference ($\approx 140\text{--}180$\,ms per video clip), alongside a modern, accessible web client built with React 19, TypeScript, and Vite. The web interface provides dual ingestion pathways (video file upload and in-browser HTML5 webcam recording), single-model inference, and multi-model consensus comparison with real-time latency and top-5 probability rankings.
\end{abstract}
