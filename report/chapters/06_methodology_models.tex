\section{Overall Recognition Pipeline}
\label{sec:overall_pipeline}
SignBridge addresses dynamic Indian Sign Language recognition through a comparative deep learning framework. Because gestures convey lexical semantics through both spatial handshape configurations and dynamic movement trajectories, three distinct model paradigms were implemented, trained, and benchmarked on identical 76-class splits:
\begin{enumerate}
    \item \textbf{Transfer Learning (MobileNetV2)}: Pre-trained spatial feature extractor with a custom classification head and temporal probability averaging.
    \item \textbf{Scratch 2D CNN (Baseline)}: A 3-block convolutional network trained from scratch with data augmentation.
    \item \textbf{Spatio-Temporal Sequence Model (CNN-LSTM)}: TimeDistributed convolutions paired with an LSTM recurrent network.
\end{enumerate}

\section{Model Architectures and Specifications}
\label{sec:arch_specs}

\subsection{MobileNetV2 (Frozen Backbone Transfer Learning)}
MobileNetV2 \cite{sandler2018mobilenetv2} leverages depthwise separable convolutions with inverted residuals and linear bottlenecks. The implemented model (\texttt{SignBridge\_MobileNetV2\_Frozen}) ingests 4D RGB tensors of shape $(33, 224, 224, 3)$ in $[0, 255]$:
\begin{itemize}
    \item \textbf{Rescaling Layer}: Maps raw pixels via $x \mapsto \frac{x}{127.5} - 1.0 \in [-1, 1]$.
    \item \textbf{Frozen Backbone}: 155-layer ImageNet backbone with \textbf{2,257,984 non-trainable parameters}. Global Average Pooling yields a 1,280-dimensional feature embedding.
    \item \textbf{Trainable Classification Head}: \texttt{Dense(256, ReLU)} (327,936 params) $\to$ \texttt{Dropout(0.3)} \cite{srivastava2014dropout} $\to$ \texttt{Dense(76, Softmax)} (19,532 params). Total trainable parameters: \textbf{347,468}.
    \item \textbf{Temporal Aggregation}: Batched forward pass over 33 frames produces frame-level probabilities $\mathbf{p}_t \in \mathbb{R}^{76}$. Video predictions average probabilities: $\bar{\mathbf{p}} = \frac{1}{33} \sum_{t=1}^{33} \mathbf{p}_t$.
\end{itemize}

\subsection{Custom 2D CNN (Scratch Baseline)}
The baseline model (\texttt{SignBridge\_CNN}) processes normalized $(33, 224, 224, 3)$ tensors in $[0, 1]$:
\begin{itemize}
    \item \textbf{Data Augmentation}: Sequential \texttt{RandomRotation(0.04)}, \texttt{RandomZoom(0.08)}, and \texttt{RandomTranslation(0.06)} active during training.
    \item \textbf{3 Conv-Pool Blocks}: \texttt{Conv2D(32, 3$\times$3)} $\to$ \texttt{MaxPool(2$\times$2)} (896 params); \texttt{Conv2D(64, 3$\times$3)} $\to$ \texttt{MaxPool(2$\times$2)} (18,496 params); and \texttt{Conv2D(128, 3$\times$3)} $\to$ \texttt{MaxPool(2$\times$2)} (73,856 params).
    \item \textbf{Head}: \texttt{GlobalAvgPool2D()} $\to$ \texttt{Dense(128, ReLU)} (16,512 params) $\to$ \texttt{Dropout(0.3)} $\to$ \texttt{Dense(76, Softmax)} (9,804 params). Total: \textbf{119,564 trainable parameters}. Frame-level probabilities are averaged across the 33 frames.
\end{itemize}

\subsection{CNN-LSTM Spatio-Temporal Model}
The recurrent network (\texttt{sequential\_3}) ingests a 5D sequence tensor $(1, 33, 112, 112, 3)$ in $[0, 1]$:
\begin{itemize}
    \item \textbf{TimeDistributed Spatial Blocks}: \texttt{TD(Conv2D(32))} $\to$ \texttt{TD(MaxPool)} (896 params); \texttt{TD(Conv2D(64))} $\to$ \texttt{TD(MaxPool)} (18,496 params); and \texttt{TD(GlobalAvgPool2D)} producing $(33, 64)$ feature steps.
    \item \textbf{Recurrent Integration}: An \texttt{LSTM(128 units, return\_sequences=False)} sequentially integrates the 33 feature steps into a 128-dimensional hidden state ($4 \times (64\times128 + 128^2 + 128) = \mathbf{98,816\text{ parameters}}$).
    \item \textbf{Head}: \texttt{Dropout(0.3)} $\to$ \texttt{Dense(76, Softmax)} (9,804 params). Total: \textbf{128,012 trainable parameters}. Directly outputs a sequence-level probability vector $\mathbf{p} \in \mathbb{R}^{76}$ without frame averaging.
\end{itemize}

\section{Training Procedure, Loss, and Optimizers}
\label{sec:training}
All models were optimized using the Adam algorithm \cite{kingma2014adam} ($\beta_1=0.9, \beta_2=0.999$) with Categorical Cross-Entropy Loss:
\begin{equation}
    \mathcal{L}_{\text{CE}} = - \sum_{k=1}^{76} y_k \log(\hat{y}_k)
    \label{eq:ce_loss}
\end{equation}
Initial learning rates ($\eta = 10^{-3}$) were adapted via \texttt{ReduceLROnPlateau} (halving $\eta$ upon validation loss plateauing for 3--5 epochs). Best checkpoints were saved via \texttt{ModelCheckpoint} to prevent overtrained weights from polluting final artifacts.

\section{Model Checkpoints and Late Fusion Strategy}
\label{sec:checkpoints_late_fusion}
Trained Keras checkpoints are stored under \texttt{backend/artifacts/}: \texttt{mobilenetv2\_frozen\_best.keras} (13.8\,MB), \texttt{cnn\_baseline\_best.keras} (1.50\,MB), and \texttt{signbridge\_cnn\_lstm\_best.keras} (1.59\,MB). In addition to standalone models, an unweighted late-fusion ensemble averages probability distributions across all three networks:
\begin{equation}
    \mathbf{p}_{\text{fusion}} = \frac{1}{3} \left( \bar{\mathbf{p}}_{\text{mob}} + \bar{\mathbf{p}}_{\text{cnn}} + \mathbf{p}_{\text{lstm}} \right) \in \mathbb{R}^{76}
    \label{eq:late_fusion}
\end{equation}
As demonstrated in Chapter \ref{ch:experiments}, late fusion achieves 60.56\% test accuracy, underperforming standalone MobileNetV2 (67.78\%) because poor scratch model predictions degrade the ensemble.
