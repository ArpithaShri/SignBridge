\chapter{Conclusion and Future Work}
\label{ch:conclusion}

\section{Summary of Achievements}
\label{sec:conclusion_summary}
This case study report presented \textbf{SignBridge}---an end-to-end deep learning framework and web application engineered to recognize 76 dynamic Indian Sign Language (ISL) word classes from video clips. 

Key verified outcomes include:
\begin{enumerate}
    \item \textbf{Standardized Preprocessing Pipeline}: Uniform 33-frame linspace extraction and area-based resizing handling diverse video containers (\texttt{.mov}, \texttt{.mp4}, \texttt{.webm}).
    \item \textbf{Multi-Model Empirical Benchmarking}: Rigorous evaluation across 76 classes on a strictly held-out 180-video test split demonstrating that \textbf{MobileNetV2} (67.78\% test accuracy, 66.42\% Macro $F_1$) substantially outperforms scratch-trained Custom CNN (5.00\%) and CNN-LSTM (4.44\%).
    \item \textbf{Low-Latency Production Backend}: A FastAPI microservice featuring in-memory singleton model weight caching that delivers sub-200\,ms CPU inference latency per video clip.
    \item \textbf{Accessible Full-Stack Web Application}: A modern React 19 / TypeScript single-page application supporting file upload, HTML5 webcam capture, and tri-model consensus comparison.
\end{enumerate}

\section{Realistic Directions for Future Work}
\label{sec:future_work}
Promising directions for future development include:
\begin{enumerate}
    \item \textbf{Dataset Expansion and Signer Diversity}: Expanding the corpus beyond 1,166 clips to thousands of samples across diverse signers, age groups, and regional ISL dialects.
    \item \textbf{Pre-trained Video Backbones & Transformers}: Exploring spatio-temporal video Transformers (e.g., TimeSformer) or fusing pre-trained spatial CNN features with multi-head self-attention mechanisms.
    \item \textbf{3D Skeletal Landmark Integration}: Fusing 3D hand and pose landmarks (e.g., MediaPipe Holistic) with RGB features via Spatial-Temporal Graph Convolutional Networks (ST-GCNs) to decouple gesture geometry from background textures and skin-tone variations.
    \item \textbf{Continuous Sign Language Translation}: Extending from isolated words to continuous sentence translation using Connectionist Temporal Classification (CTC) or sequence-to-sequence encoder-decoders.
    \item \textbf{Client-Side Edge Deployment}: Exporting MobileNetV2 to TensorFlow Lite / ONNX for direct in-browser inference via WebAssembly (Wasm) or WebGPU.
\end{enumerate}
